# トラブルシューティングガイド

VGC2使用時によくある問題とその解決方法をまとめています。問題が発生した場合は、このガイドを参照してください。

## インストール・導入時の問題

### インポートエラーが発生する

#### 症状
- UnityPackageのインポート時にエラーが表示される
- スクリプトコンパイルエラーが発生する

#### 原因
- 必要な依存関係がインストールされていない
- Unityのバージョンが古い
- VRChat SDKのバージョンが合わない

#### 解決方法
1. **Unity バージョンの確認**
   ```
   推奨: Unity 2022.3.22f1
   最小: Unity 2022.3.6f1
   ```

2. **VRChat SDK の確認**
   - VRChat SDK 3.8.2以降がインストールされているか確認
   - SDK Control Panelでエラーがないか確認

3. **UdonSharp の確認**
   - 最新版のUdonSharpがインストールされているか確認
   - Package Managerから再インストール

### プレハブが見つからない

#### 症状
- VoiceGroupControl2.prefabが見つからない
- Prefabsフォルダが空

#### 解決方法
1. インポート時にすべてのファイルが選択されていたか確認
2. `Assets/mikinel/VoiceGroupControl2` フォルダを確認
3. 再度UnityPackageをインポート

### スクリプトエラーが表示される

#### 症状
- "The type or namespace name 'UdonSharp' could not be found"
- コンポーネントが missing になっている

#### 解決方法
1. UdonSharpを先にインストール
2. プロジェクトを再起動
3. スクリプトを再コンパイル（Ctrl+R）

## 音声関連の問題

### 音声が聞こえない

#### 症状
- グループ内でも音声が聞こえない
- 特定のプレイヤーの音声だけ聞こえない

#### 確認事項
- [ ] VGCGroupAreaが正しく配置されているか
- [ ] Group IDが正しく設定されているか
- [ ] Master Volumeが0になっていないか
- [ ] グループ間の音量設定が0になっていないか

#### 解決方法

1. **デバッグモードで確認**
   ```csharp
   VoiceGroupControl2.DebugMode = true;
   ```
   - プレイヤーの所属グループを確認
   - エリアの範囲を可視化

2. **基本設定の確認**
   - Master Volume: 1.0
   - Number of Groups: エリア数以上
   - Update Interval: 0.1

3. **Configuratorで設定確認**
   - グループ間マトリックスの値を確認
   - 対角線上（同じグループ）が1.0になっているか

### 音声が途切れる

#### 症状
- エリア境界で音声がブツブツ切れる
- ランダムに音声が途切れる

#### 原因
- エリア境界の設定が不適切
- パフォーマンスの問題
- ネットワークの問題

#### 解決方法

1. **エリア境界の調整**
   ```
   Fade Distance: 2.0～3.0に設定
   エリア間に少し重なりを持たせる
   ```

2. **パフォーマンス設定の調整**
   - Performance Mode: Low に変更
   - Update Interval: 0.2 に増やす
   - Max Active Players: 減らす

### 音声が二重に聞こえる

#### 症状
- エコーのように聞こえる
- 同じ音声が重複して聞こえる

#### 原因
- 複数のVGC2システムが動作している
- グループエリアが重複している

#### 解決方法
1. VoiceGroupControl2.prefabが1つだけか確認
2. Group IDの重複を確認
3. エリアのPriorityを適切に設定

## マイク機能の問題

### マイクが動作しない

#### 症状
- マイクを持っても音声が拡声されない
- マイクのUIが表示されない

#### 確認事項
- [ ] VGCMicrophone.prefabが正しく配置されているか
- [ ] Microphone IDが重複していないか
- [ ] Colliderが有効になっているか

#### 解決方法
1. マイクのLayerを確認（通常はPickup）
2. Amplification Rangeを確認（デフォルト: 50）
3. Volume Multiplierを確認（デフォルト: 2.0）

### ハウリングが発生する

#### 症状
- キーンという高音が発生
- 音声がループして増幅される

#### 解決方法
1. **エコーキャンセルを有効化**
   ```
   Enable Echo Cancellation: true
   ```

2. **音量を調整**
   - Volume Multiplier を下げる（1.5程度）
   - マイク同士の距離を離す

3. **指向性モードを使用**
   ```
   Directional Mode: true
   Pickup Angle: 90°
   ```

## トランシーバー機能の問題

### チャンネルに接続できない

#### 症状
- チャンネルを選択しても通信できない
- 他のプレイヤーの音声が聞こえない

#### 確認事項
- [ ] 同じチャンネルに設定されているか
- [ ] PTTボタンが正しく動作しているか
- [ ] チャンネル権限があるか

#### 解決方法
1. チャンネル番号を再確認
2. PTT Modeを確認（Hold/Toggle/Voice）
3. Audio Qualityを下げてテスト

### 全チャンネル発報が機能しない

#### 症状
- All Callボタンが反応しない
- 一部のチャンネルにしか届かない

#### 解決方法
1. All Call権限を確認
2. 各チャンネルの受信設定を確認
3. ネットワーク帯域を確認

## セーブ・ロード機能の問題

### 設定が保存されない

#### 症状
- Saveボタンを押しても保存されない
- ワールドを出ると設定が消える

#### 確認事項
- [ ] VRChat Persistenceが有効か
- [ ] 保存容量に余裕があるか
- [ ] 権限設定が適切か

#### 解決方法
1. **Persistence設定を確認**
   ```
   Use VRChat Persistence: true
   Persistence Scope: Player
   ```

2. **手動でJSONエクスポート**
   - バックアップとして外部保存
   - 必要時にインポート

### プリセットが読み込めない

#### 症状
- Loadボタンが反応しない
- エラーメッセージが表示される

#### 解決方法
1. プリセットのバージョンを確認
2. 破損したプリセットを削除
3. JSONインポートで復元

## パフォーマンスの問題

### FPSが低下する

#### 症状
- ワールドが重くなる
- カクつきが発生する

#### 最適化方法

1. **基本的な最適化**
   ```
   Performance Mode: Low
   Update Interval: 0.2
   Max Active Players: 20
   ```

2. **LOD設定の調整**
   ```
   LOD Distance: 30.0
   ```

3. **不要な機能の無効化**
   - 使用しないマイクを削除
   - 不要なパネルを削除

### メモリ使用量が多い

#### 症状
- Unityのメモリ使用量が増加
- クラッシュが発生する

#### 解決方法
1. Pool Sizeを調整（20-30に減らす）
2. Cache Durationを短くする（30秒）
3. グループ数を必要最小限に

## VRChat固有の問題

### ビルドエラー

#### 症状
- Build & Publishでエラーが発生
- アップロードできない

#### 確認事項
- [ ] VRChat SDKが最新か
- [ ] シーン内のエラーがないか
- [ ] ポリゴン数/マテリアル数が制限内か

#### 解決方法
1. SDK Control Panelでエラーを修正
2. ConsoleウィンドウでErrorを確認
3. 最小構成でテスト

### ワールドで動作しない

#### 症状
- ローカルでは動作するがVRChatでは動作しない
- 一部の機能が使えない

#### 解決方法
1. Udon Behaviourの同期設定を確認
2. ネットワーク関連の設定を確認
3. VRChatのログを確認

## デバッグ方法

### デバッグモードの活用

1. **有効化方法**
   ```csharp
   Debug Mode: true
   Show Group Areas: true
   ```

2. **確認できる情報**
   - プレイヤーの所属グループ
   - エリアの範囲
   - 現在の設定値

### ログの確認

1. **Unityコンソール**
   - エラーと警告を確認
   - VGC2関連のログをフィルター

2. **VRChatログ**
   ```
   %AppData%\..\LocalLow\VRChat\VRChat\
   ```

### サポートへの報告

問題が解決しない場合：

1. **必要な情報**
   - Unity バージョン
   - VRChat SDK バージョン
   - エラーメッセージ
   - 再現手順

2. **報告先**
   - Booth のメッセージ機能
   - Discord サポートチャンネル

## まとめ

多くの問題は基本的な設定の確認で解決できます。このガイドで解決しない場合は、デバッグ情報を添えてサポートにお問い合わせください。
