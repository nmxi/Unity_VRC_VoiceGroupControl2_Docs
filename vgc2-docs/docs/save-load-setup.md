# セーブ・ロード機能の設定ガイド

VGC2のセーブ・ロード機能を使用すると、音声設定をプリセットとして保存し、必要に応じて呼び出すことができます。VRChat Persistenceを利用した永続保存やJSON形式でのエクスポート/インポートにも対応しています。

## セーブ・ロード機能の概要

この機能により、以下のことが可能になります：

- **設定のプリセット保存**（最大10プリセット）
- **VRChat Persistenceによる永続保存**
- **JSON形式でのエクスポート/インポート**
- **UnityEditor上での設定適用**

## セーブ・ロードパネルの追加

### 1. パネルの配置

1. `Assets/mikinel/VoiceGroupControl2/Prefabs` フォルダを開きます
2. `VGCSaveLoadPanel.prefab` を見つけます
3. ワールド内の適切な位置に配置します

:::tip 配置場所の推奨
- コントロールルームや管理エリア
- スタッフがアクセスしやすい場所
- 一般プレイヤーから見えない位置（権限制御する場合）
:::

### 2. パネルの基本設定

#### Panel Access Control
- Public: 全員がアクセス可能
- Staff Only: スタッフのみ使用可能
- Owner Only: ワールドオーナーのみ

#### Max Presets
- 保存可能なプリセット数（1-10）
- デフォルト: 5

#### Auto Save Interval
- 自動保存の間隔（秒）
- 0で自動保存無効
- デフォルト: 300（5分）

## プリセット管理

### プリセットの保存

1. **現在の設定を保存**
   - 「Save Current」ボタンをクリック
   - プリセット名を入力
   - 保存完了

2. **保存される内容**
   - グループ間の音量設定
   - マイクの設定
   - トランシーバーのチャンネル設定
   - その他のVGC2パラメータ

### プリセットの読み込み

1. プリセットリストから選択
2. 「Load」ボタンをクリック
3. 設定が即座に適用される

### プリセットの管理

#### Rename Preset
1. プリセットを選択
2. 「Rename」ボタンをクリック
3. 新しい名前を入力

#### Delete Preset
1. プリセットを選択
2. 「Delete」ボタンをクリック
3. 確認ダイアログで「Yes」

#### Duplicate Preset
1. プリセットを選択
2. 「Duplicate」ボタンをクリック
3. コピーが作成される

## VRChat Persistenceを使用した保存

### Persistence設定

VRChat Persistenceを有効にすることで、ワールドを離れても設定が保持されます。

#### Enable Persistence
- オンにするとVRChat Persistenceが有効
- プレイヤーごとに設定を保存

#### Persistence Scope
- Player: プレイヤーごと
- Instance: インスタンスごと
- Global: 全インスタンス共通

### 自動保存設定

#### Auto Save on Change
- 設定変更時に自動保存
- デフォルト: オン

#### Save Cooldown
- 連続保存を防ぐクールダウン時間
- デフォルト: 5秒

## JSON形式でのエクスポート/インポート

### エクスポート機能

1. **エクスポート手順**
   - 「Export to JSON」ボタンをクリック
   - JSON文字列が表示される
   - コピーして外部に保存

2. **エクスポートされる内容**
```json
{
  "version": "2.0",
  "timestamp": "2024-01-01T00:00:00Z",
  "settings": {
    "groupVolumes": [[1.0, 0.5, 0.0], [0.5, 1.0, 0.5], [0.0, 0.5, 1.0]],
    "micSettings": {...},
    "transceiverSettings": {...}
  }
}
```

### インポート機能

1. **インポート手順**
   - 「Import from JSON」ボタンをクリック
   - JSON文字列を貼り付け
   - 「Apply」をクリック

2. **検証機能**
   - 形式の自動チェック
   - バージョン互換性の確認
   - エラー時の詳細表示

## UnityEditor上での設定適用

### Editor専用機能

開発時に便利な機能：

1. **Export for Editor**
   - Editor用の設定ファイルを生成
   - ScriptableObjectとして保存

2. **設定の適用手順**
   1. Play Modeで設定を調整
   2. 「Export for Editor」でエクスポート
   3. Play Mode終了
   4. エクスポートした設定を適用

### デバッグ機能

#### Show Debug Info
- 現在の設定値を表示
- メモリ使用量の確認
- Persistence状態の確認

#### Validate Settings
- 設定の整合性チェック
- 問題がある場合は警告表示

## 高度な使用方法

### プリセットのカテゴリ分け

プリセットをカテゴリで管理：

```
イベント用/
  - オープニング
  - メイン
  - エンディング
  
ゲーム用/
  - バトルモード
  - 探索モード
  - 待機モード
```

### 条件付き自動切り替え

特定の条件でプリセットを自動切り替え：

1. **Time-based Switching**
   - 時間帯による切り替え
   - イベントスケジュールに対応

2. **Player Count Based**
   - プレイヤー数による調整
   - 混雑時の最適化

3. **Area Based**
   - エリアごとの設定切り替え
   - シーン転換に対応

## トラブルシューティング

### 保存できない

確認事項：
- [ ] Persistence権限があるか
- [ ] 保存容量に余裕があるか
- [ ] パネルの権限設定が正しいか

### 読み込みエラー

対処法：
1. プリセットの整合性を確認
2. バージョンの互換性をチェック
3. 破損したプリセットを削除

### JSONインポートエラー

対処法：
1. JSON形式を検証
2. 必須フィールドの確認
3. 文字エンコーディングの確認

## ベストプラクティス

### プリセット命名規則

分かりやすい名前を付ける：

```
良い例：
- "イベント_オープニング_v1"
- "通常営業_平日_昼"
- "ゲーム_バトルロイヤル_50人"

悪い例：
- "設定1"
- "test"
- "aaa"
```

### バックアップの推奨

1. **定期的なエクスポート**
   - 週1回はJSON形式でバックアップ
   - 重要な変更後は必ずエクスポート

2. **バージョン管理**
   - 変更履歴を記録
   - 以前の設定に戻せるように

### チーム運用

1. **権限管理**
   - 編集権限者を限定
   - 変更ログの記録

2. **共有方法**
   - JSONファイルでの共有
   - ドキュメント化
