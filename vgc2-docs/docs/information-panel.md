# インフォメーションパネルの追加

VGC2のインフォメーションパネル(InformationPanel)を使用すると、プレイヤーが現在所属しているグループやマイクの使用状況をリアルタイムで確認できます。

<ClickableImage src="/img/information-panel--hero.png" alt="InformationPanel概要" />

## InformationPanelの配置

1. `Assets/mikinel/VoiceGroupControl2/Prefabs/VGCPanels` フォルダを開きます

<ClickableImage src="/img/transceiver-setup--prefab-location.png" alt="InformationPanelプレハブの場所" />

2. `VGCInformationPanel.prefab` を見つけます
3. シーン上に配置します
