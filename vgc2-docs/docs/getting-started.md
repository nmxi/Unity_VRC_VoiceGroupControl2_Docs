# はじめに

## VGC2とは

VoiceGroupControl2は、VRChatワールドでプレイヤーの音声を細かく制御するためのシステムです。

### 使用例

- **大規模イベント**: 司会者と参加者の音声を分離
- **ロールプレイ**: 部屋ごとに音声を遮断
- **ゲームワールド**: チーム間の音声を制御

## 必要な環境

- Unity 2019.4.31f1
- VRChat SDK3-Worlds
- UdonSharp

## 基本概念

### グループ
プレイヤーは3D空間の「グループエリア」に入ることで自動的にグループに所属します。

### 音声制御
同じグループ内のプレイヤー同士は通常通り会話でき、異なるグループ間の音声は設定により制御されます。

### マイク・トランシーバー
特殊なアイテムを使用することで、グループの枠を超えて音声を届けることができます。
