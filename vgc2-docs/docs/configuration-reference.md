# 設定リファレンス

VGC2の全パラメータと設定項目の詳細なリファレンスです。各設定の意味、値の範囲、デフォルト値、使用例を記載しています。

## VoiceGroupControl2コンポーネント

### 基本設定

#### Number of Groups
- **説明**: 使用するグループの数
- **データ型**: int
- **範囲**: 1～32
- **デフォルト**: 4
- **使用例**: イベント会場なら5-10、ゲームワールドなら2-4が推奨

#### Master Volume
- **説明**: システム全体のマスター音量
- **データ型**: float
- **範囲**: 0.0～2.0
- **デフォルト**: 1.0
- **使用例**: 通常は1.0、静かめの環境では0.7-0.8

#### Update Interval
- **説明**: システムの更新間隔（秒）
- **データ型**: float
- **範囲**: 0.016～1.0
- **デフォルト**: 0.1
- **使用例**: 高精度が必要な場合は0.05、パフォーマンス重視なら0.2

### パフォーマンス設定

#### Performance Mode
- **説明**: パフォーマンス最適化モード
- **データ型**: enum
- **値**:
  - Low: 低負荷モード
  - Normal: 標準モード
  - High: 高品質モード
- **デフォルト**: Normal

#### Max Active Players
- **説明**: 同時処理する最大プレイヤー数
- **データ型**: int
- **範囲**: 1～80
- **デフォルト**: 40
- **使用例**: Quest対応なら20、PC専用なら40-60

#### LOD Distance
- **説明**: LOD（Level of Detail）が適用される距離
- **データ型**: float
- **範囲**: 10.0～200.0
- **デフォルト**: 50.0

### デバッグ設定

#### Debug Mode
- **説明**: デバッグ表示の有効/無効
- **データ型**: bool
- **デフォルト**: false
- **注意**: リリース時は必ずfalseに

#### Show Group Areas
- **説明**: グループエリアの可視化
- **データ型**: bool
- **デフォルト**: false

## VGCGroupArea設定

### 基本パラメータ

#### Group ID
- **説明**: このエリアが所属するグループID
- **データ型**: int
- **範囲**: 0～31
- **デフォルト**: 0
- **重要**: 重複しないように設定

#### Priority
- **説明**: エリアの優先度（重複時の判定に使用）
- **データ型**: int
- **範囲**: 0～100
- **デフォルト**: 50
- **使用例**: 重要なエリアは高く（70-90）、通路などは低く（20-30）

#### Fade Distance
- **説明**: エリア境界でのフェード距離
- **データ型**: float
- **範囲**: 0.0～10.0
- **デフォルト**: 2.0
- **使用例**: シームレスな切り替えなら2-3、明確な境界なら0.5-1

### 高度な設定

#### Override Voice Settings
- **説明**: このエリア専用の音声設定を使用
- **データ型**: bool
- **デフォルト**: false

#### Custom Voice Gain
- **説明**: カスタム音声ゲイン（Override有効時）
- **データ型**: float
- **範囲**: 0.0～5.0
- **デフォルト**: 1.0

#### Custom Max Distance
- **説明**: カスタム最大可聴距離（Override有効時）
- **データ型**: float
- **範囲**: 1.0～100.0
- **デフォルト**: 25.0

## 音声パラメータ

### Voice Gain設定

#### Base Voice Gain
- **説明**: 基本音声ゲイン
- **データ型**: float
- **範囲**: 0.0～5.0
- **デフォルト**: 1.0
- **推奨値**:
  - 静かな環境: 0.8-1.0
  - 通常環境: 1.0-1.2
  - 騒がしい環境: 1.2-1.5

#### Group Voice Gain Matrix
- **説明**: グループ間の音声ゲインマトリックス
- **データ型**: float[,]
- **範囲**: 各要素 0.0～2.0
- **デフォルト**: 対角線1.0、その他0.0

### Voice Distance設定

#### Default Min Distance
- **説明**: デフォルトの最小可聴距離
- **データ型**: float
- **範囲**: 0.1～10.0
- **デフォルト**: 1.0

#### Default Max Distance
- **説明**: デフォルトの最大可聴距離
- **データ型**: float
- **範囲**: 5.0～100.0
- **デフォルト**: 25.0

#### Distance Falloff Curve
- **説明**: 距離減衰カーブ
- **データ型**: AnimationCurve
- **デフォルト**: Linear falloff

### 音声フェード設定

#### Fade In Time
- **説明**: 音声フェードイン時間
- **データ型**: float
- **範囲**: 0.0～2.0
- **デフォルト**: 0.3
- **使用例**: スムーズな切り替えなら0.5-1.0

#### Fade Out Time
- **説明**: 音声フェードアウト時間
- **データ型**: float
- **範囲**: 0.0～2.0
- **デフォルト**: 0.3

## マイク設定パラメータ

### 基本設定

#### Microphone ID
- **説明**: マイクの識別ID
- **データ型**: int
- **範囲**: 0～15
- **デフォルト**: 0

#### Microphone Mode
- **説明**: マイクの動作モード
- **データ型**: enum
- **値**:
  - 0: UserOnly（使用者のみ）
  - 1: UserAndNearby（使用者+周囲）
  - 2: NearbyOnly（周囲のみ）
- **デフォルト**: 0

#### Amplification Range
- **説明**: 拡声範囲
- **データ型**: float
- **範囲**: 10.0～200.0
- **デフォルト**: 50.0

### 詳細設定

#### Volume Multiplier
- **説明**: 音量増幅率
- **データ型**: float
- **範囲**: 1.0～5.0
- **デフォルト**: 2.0

#### Pickup Range
- **説明**: 音声ピックアップ範囲（Mode 1,2用）
- **データ型**: float
- **範囲**: 1.0～20.0
- **デフォルト**: 5.0

#### Directional Mode
- **説明**: 指向性モード
- **データ型**: bool
- **デフォルト**: false

#### Pickup Angle
- **説明**: ピックアップ角度（指向性モード時）
- **データ型**: float
- **範囲**: 30.0～180.0
- **デフォルト**: 120.0

## トランシーバー設定

### チャンネル設定

#### Available Channels
- **説明**: 使用可能なチャンネル数
- **データ型**: int
- **範囲**: 1～12
- **デフォルト**: 12

#### Default Channel
- **説明**: デフォルトチャンネル
- **データ型**: int
- **範囲**: 1～12
- **デフォルト**: 1

#### Channel Names
- **説明**: 各チャンネルの名前
- **データ型**: string[]
- **デフォルト**: "Channel 1"～"Channel 12"

### 音声品質設定

#### Audio Quality
- **説明**: 音声品質レベル
- **データ型**: enum
- **値**:
  - Low: 低品質（8kHz）
  - Medium: 中品質（16kHz）
  - High: 高品質（48kHz）
- **デフォルト**: Medium

#### Noise Suppression Level
- **説明**: ノイズ抑制レベル
- **データ型**: float
- **範囲**: 0.0～1.0
- **デフォルト**: 0.5

### PTT設定

#### PTT Mode
- **説明**: Push-to-Talkモード
- **データ型**: enum
- **値**:
  - Hold: 押している間送信
  - Toggle: 切り替え式
  - Voice: 音声検出
- **デフォルト**: Hold

#### Voice Activation Threshold
- **説明**: 音声起動しきい値（Voice mode時）
- **データ型**: float
- **範囲**: -60.0～-20.0 dB
- **デフォルト**: -35.0

## セーブ・ロード設定

### 保存設定

#### Max Presets
- **説明**: 最大プリセット数
- **データ型**: int
- **範囲**: 1～10
- **デフォルト**: 5

#### Auto Save Enabled
- **説明**: 自動保存の有効/無効
- **データ型**: bool
- **デフォルト**: true

#### Auto Save Interval
- **説明**: 自動保存間隔（秒）
- **データ型**: float
- **範囲**: 60.0～3600.0
- **デフォルト**: 300.0

### Persistence設定

#### Use VRChat Persistence
- **説明**: VRChat Persistenceの使用
- **データ型**: bool
- **デフォルト**: true

#### Persistence Scope
- **説明**: Persistenceの範囲
- **データ型**: enum
- **値**:
  - Player: プレイヤーごと
  - Instance: インスタンスごと
  - Global: 全体共通
- **デフォルト**: Player

- **デフォルト**: 10.0

#### Audio Update Rate
- **説明**: 音声設定の更新頻度
- **データ型**: float
- **範囲**: 1.0～30.0 Hz
- **デフォルト**: 5.0

#### Pool Size
- **説明**: オブジェクトプールサイズ
- **データ型**: int
- **範囲**: 10～100
- **デフォルト**: 40

#### Cache Duration
- **説明**: キャッシュ保持時間（秒）
- **データ型**: float
- **範囲**: 10.0～300.0
- **デフォルト**: 60.0

Update Interval: 0.1
Performance Mode: Normal
Max Active Players: 50
```

Master Volume: 1.2
Update Interval: 0.05
Performance Mode: High
Max Active Players: 20
```

```
Number of Groups: 6
Master Volume: 0.8
Update Interval: 0.2
Performance Mode: Low
Max Active Players: 30
```
