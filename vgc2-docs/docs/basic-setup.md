# 基本導入ガイド

VGC2の最小構成での導入手順を詳しく説明します。このガイドに従って、基本的な音声グループ制御を実装できます。

## 前提条件

導入前に以下の環境が整っていることを確認してください：

- Unity 2022.3.22f1
- VRChat SDK 3.8.2以降
- UdonSharp
- VGC2パッケージ（購入またはダウンロード済み）

## 1. VoiceGroupControl2.prefabの配置

### 1.1 プレハブの場所

1. Unityプロジェクトを開きます
2. Projectウィンドウで `Assets/mikinel/VoiceGroupControl2` フォルダを開きます
3. `VoiceGroupControl2.prefab` を見つけます


### 1.2 シーンへの配置

1. `VoiceGroupControl2.prefab` をHierarchyウィンドウにドラッグ&ドロップします
2. 配置位置は通常、ワールドの原点（0, 0, 0）に設定します
3. **重要**: このプレハブはシーンに1つだけ配置してください

:::tip 配置のポイント
VGC2システムの中核となるプレハブです。複数配置すると競合が発生する可能性があります。
:::

## 2. VGCGroupAreaの追加と設定

### 2.1 VGCGroupAreaとは

VGCGroupAreaは、プレイヤーが属するグループを決定するエリアです。このエリア内にいるプレイヤーは同じグループとして扱われます。

### 2.2 VGCGroupAreaの配置

1. `Assets/mikinel/VoiceGroupControl2/Prefabs` フォルダを開きます
2. `VGCGroupArea.prefab` をシーンに必要な数だけ配置します
3. 各エリアを適切な位置に移動します

### 2.3 Group IDの設定

各VGCGroupAreaには一意のGroup IDを設定する必要があります：

1. 配置したVGCGroupAreaを選択
2. InspectorでGroup IDを設定（0から順番に）
3. 例：最初のエリアは0、次は1、その次は2...


### 2.4 エリアサイズの調整

1. VGCGroupAreaを選択
2. Scaleを調整してエリアサイズを変更
3. プレイヤーが快適に移動できるサイズに設定

:::note エリアサイズの目安
- 小規模な部屋: Scale (10, 3, 10)
- 中規模なホール: Scale (20, 4, 20)
- 大規模な屋外エリア: Scale (50, 10, 50)
:::

### 2.5 デバッグモードでの確認

開発中はエリアを可視化して確認できます：

1. VoiceGroupControl2オブジェクトを選択
2. Inspectorで「Debug Mode」をオンにする
3. Play modeで各エリアが色分けされて表示されます

## 3. Configuratorでの音量設定

### 3.1 Configuratorの起動

1. UnityでPlay modeに入ります
2. Gameビューで「VGC2 Configurator」ボタンをクリック
3. Configuratorウィンドウが開きます


### 3.2 グループ間音量の調整

Configuratorでは、各グループ間の音声の聞こえ方を設定できます：

1. **縦軸**: 音を聞く側のグループ
2. **横軸**: 音を発する側のグループ
3. **数値**: 0.0（無音）から1.0（最大音量）

#### 設定例

- 同じグループ内: 1.0（最大音量）
- 隣接グループ: 0.5（半分の音量）
- 離れたグループ: 0.0（聞こえない）

### 3.3 デフォルト設定

初期状態では以下の設定になっています：

- 同じグループ内の音声: 100%
- 異なるグループ間の音声: 0%

### 3.4 設定の保存

1. 設定が完了したら「Save」ボタンをクリック
2. 設定がプロジェクトに保存されます

## 4. 設定の適用と確認

### 4.1 設定の適用

1. Configuratorで「Apply」ボタンをクリック
2. 設定が即座に反映されます
3. Play modeのまま動作確認ができます

### 4.2 動作確認のポイント

以下の点を確認してください：

- [ ] 各エリアに入ると正しいグループに所属するか
- [ ] グループ間の音量設定が正しく反映されているか
- [ ] エリアの境界での切り替えがスムーズか
- [ ] 複数プレイヤーでの動作が正常か

### 4.3 テスト方法

1. Unity内でVRChatのローカルテストを使用
2. 複数のテストアカウントでワールドに入る
3. 各エリアでの音声の聞こえ方を確認

## 5. VRChatへのアップロード

### 5.1 ビルド前のチェックリスト

アップロード前に以下を確認してください：

- [ ] VRChat SDKのコントロールパネルでエラーがないか
- [ ] すべてのVGCGroupAreaにGroup IDが設定されているか
- [ ] Configuratorの設定が保存されているか
- [ ] Debug Modeがオフになっているか

### 5.2 Build & Testでのローカルテスト

1. VRChat SDK Control Panelを開く
2. 「Build & Test」をクリック
3. ローカルでワールドが起動します
4. 実際のVRChat環境で動作確認

### 5.3 本番アップロード

1. テストで問題がないことを確認
2. VRChat SDK Control Panelで「Build & Publish for Windows」をクリック
3. ワールド情報を入力してアップロード

:::warning アップロード時の注意
初回アップロード時は「Community Labs」に公開されます。十分なテストを行ってから一般公開してください。
:::

## まとめ

これで基本的なVGC2の導入が完了しました。この設定により：

- プレイヤーがエリアごとにグループ分けされる
- グループ間の音声制御が可能になる
- イベントやゲームでの音声分離が実現できる
