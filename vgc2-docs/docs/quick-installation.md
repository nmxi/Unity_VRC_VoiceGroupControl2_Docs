# クイックインストール

## 手順

### 1. パッケージのインポート

1. VGC2のUnityPackageをダウンロード
2. Unityプロジェクトにインポート
3. 必要な依存関係を確認

### 2. プレハブの配置

1. `Prefabs/VoiceGroupControl2.prefab` をシーンに配置
2. 位置を調整（通常は原点に配置）

### 3. グループエリアの設定

1. `Prefabs/VGCGroupArea.prefab` を必要な数だけ配置
2. 各エリアのサイズと位置を調整
3. Group IDを設定（0から順番に）

### 4. 動作確認

1. VRChat SDK Control Panelから「Build & Test」
2. ローカルテストで動作を確認

## 次のステップ

基本的な設定が完了したら、VRChatでテストして動作を確認してください。
