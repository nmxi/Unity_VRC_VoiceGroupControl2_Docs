# マイク機能の設定ガイド

VGC2のマイク機能を使用すると、イベント司会や案内役として効果的に音声を拡声できます。3つのモードから用途に応じて選択できます。

## マイク機能の概要

VGC2のマイクは、特定のプレイヤーの音声を増幅し、より広範囲に届けることができる機能です。

### 3つのマイクモード

1. **使用者のみ拡声**
   - マイクを持っているプレイヤーの音声のみを拡声
   - 司会者や発表者に最適

2. **使用者+近くのプレイヤーを拡声**
   - マイクを持っているプレイヤーとその周囲のプレイヤーの音声を拡声
   - インタビューや対談に最適

3. **近くのプレイヤーを常に拡声**
   - マイクの近くにいるプレイヤーの音声を常に拡声
   - 固定マイクやステージマイクに最適

## マイクプレハブの追加

### 1. マイクプレハブの配置

1. `Assets/mikinel/VoiceGroupControl2/Prefabs` フォルダを開きます
2. `VGCMicrophone.prefab` を見つけます
3. シーンの適切な位置にドラッグ&ドロップします

:::tip 配置のヒント
- ステージ上や発表エリアに配置すると効果的です
- 複数のマイクを配置することも可能です
:::

### 2. マイクの基本設定

マイクを選択してInspectorで以下を設定します：

#### Microphone ID
- 各マイクに一意のIDを設定（0から順番に）
- 複数マイク使用時は重複しないよう注意

#### Microphone Mode
- 0: 使用者のみ拡声
- 1: 使用者+近くのプレイヤーを拡声
- 2: 近くのプレイヤーを常に拡声

#### Amplification Range
- 音声が届く範囲（メートル単位）
- デフォルト: 50m
- 会場の大きさに応じて調整

## 詳細設定パラメータ

### 音量設定

#### Base Volume Multiplier
- 基本音量の倍率
- デフォルト: 2.0
- 範囲: 1.0～5.0

#### Distance Falloff
- 距離による音量減衰の設定
- デフォルト: Linear
- オプション: Linear, Logarithmic, None

### 拡声範囲の詳細設定

#### Near Field Range
- 近距離での音声範囲
- デフォルト: 5m
- インタビューモードで重要

#### Pickup Angle
- 音声を拾う角度（度）
- デフォルト: 180°
- 指向性マイクとして使用する場合は狭く設定

### エフェクト設定

#### Enable Echo Cancellation
- エコーキャンセル機能
- デフォルト: オン
- ハウリング防止に有効

#### Noise Gate Threshold
- ノイズゲートの閾値
- デフォルト: -40dB
- 背景ノイズを除去

## マイクの使い方

### 司会者モードでの使用

1. Microphone Modeを0に設定
2. 司会者がマイクを持つ
3. 音声が会場全体に届く

```
設定例：
- Microphone Mode: 0
- Amplification Range: 100m
- Base Volume Multiplier: 3.0
```

### インタビューモードでの使用

1. Microphone Modeを1に設定
2. インタビュアーがマイクを持つ
3. 対象者の近くで使用

```
設定例：
- Microphone Mode: 1
- Amplification Range: 50m
- Near Field Range: 3m
- Base Volume Multiplier: 2.5
```

### ステージマイクとしての使用

1. Microphone Modeを2に設定
2. ステージ上に固定配置
3. 演者が近づくと自動的に拡声

```
設定例：
- Microphone Mode: 2
- Amplification Range: 80m
- Near Field Range: 2m
- Pickup Angle: 120°
```

## リスポーン機能

マイクには自動リスポーン機能があります。

### リスポーン設定

#### Enable Auto Respawn
- 自動リスポーンの有効/無効
- デフォルト: オン

#### Respawn Time
- リスポーンまでの時間（秒）
- デフォルト: 10秒

#### Respawn Position
- リスポーン位置
- オプション: Original Position, Spawn Point

### リスポーンポイントの設定

1. 空のGameObjectを作成
2. 「MicrophoneSpawnPoint」とタグ付け
3. 希望の位置に配置

## 複数マイクの管理

### マイクの優先順位

複数のマイクが同時に使用される場合：

1. **Microphone Priority**で優先順位を設定
2. 数値が低いほど優先度が高い
3. 同じ優先度の場合は距離で判定

### グループ別マイク設定

特定のグループ専用マイクの作成：

1. **Target Groups**で対象グループを指定
2. 複数グループを選択可能
3. 空欄の場合は全グループ対象

## トラブルシューティング

### マイクが機能しない

確認事項：
- [ ] VoiceGroupControl2.prefabが配置されているか
- [ ] Microphone IDが重複していないか
- [ ] マイクのColliderが有効か

### 音声が聞こえない

確認事項：
- [ ] Amplification Rangeが適切か
- [ ] Base Volume Multiplierが0になっていないか
- [ ] Target Groupsの設定が正しいか

### ハウリングが発生する

対処法：
1. Echo Cancellationを有効にする
2. Base Volume Multiplierを下げる
3. マイク同士の距離を離す

## ベストプラクティス

### イベント運営での活用

1. **メインマイク**と**サブマイク**を用意
2. 優先順位を適切に設定
3. リスポーン機能で紛失対策

### パフォーマンスの最適化

1. 使用しないマイクは無効化
2. Amplification Rangeは必要最小限に
3. エフェクトは必要なもののみ有効化

### 演出としての活用

1. マイクの見た目をカスタマイズ
2. パーティクルエフェクトを追加
3. 使用時のアニメーション設定

## まとめ

マイク機能を適切に設定することで：

- イベントの司会進行がスムーズに
- 参加者全員に音声が届く
- インタラクティブな演出が可能

次は[トランシーバー機能](/docs/transceiver-setup)でスタッフ間の連携を強化しましょう。
