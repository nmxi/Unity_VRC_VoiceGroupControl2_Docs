# トランシーバー機能の設定ガイド

VGC2のトランシーバー機能を使用すると、ワールド内の離れた場所にいるプレイヤー同士でリアルタイムに通話できます。12チャンネルのシステムで、スタッフ間の連絡や チーム戦での通信に最適です。

## トランシーバー機能の概要

トランシーバーは、同じチャンネルに接続しているプレイヤー間で音声通信を可能にする機能です。

### 主な特徴

- **12チャンネル対応**（1ch～12ch）
- **全チャンネル発報機能**
- **プッシュ・トゥ・トーク（PTT）対応**
- **距離に関係なく通信可能**

## トランシーバーコントロールパネルの追加

### 1. コントロールパネルの配置

1. `Assets/mikinel/VoiceGroupControl2/Prefabs` フォルダを開きます
2. `VGCTransceiverPanel.prefab` を見つけます
3. ワールド内の適切な位置に配置します

:::tip 配置場所の推奨
- スタッフルームや控室
- 指令室やコントロールルーム
- プレイヤーがアクセスしやすい場所
:::

### 2. パネルの基本設定

#### Panel ID
- 各パネルに一意のIDを設定（0から順番に）
- 複数パネル使用時は重複を避ける

#### Default Channel
- 初期状態のチャンネル（1～12）
- デフォルト: 1ch

#### Allow Channel Change
- プレイヤーがチャンネルを変更できるか
- デフォルト: オン

## チャンネルシステムの詳細

### チャンネルの仕組み

各チャンネルは独立した通信回線として機能します：

1. **1ch～12ch**: 通常の通信チャンネル
2. **All Call**: 全チャンネルへの一斉送信

### チャンネル設定

#### Channel Permissions
各チャンネルへのアクセス権限を設定：

```
設定例：
- チャンネル1-3: 全員アクセス可能
- チャンネル4-6: スタッフのみ
- チャンネル7-12: 特定グループのみ
```

#### Channel Names
カスタムチャンネル名の設定：

1. Inspector で「Custom Channel Names」を有効化
2. 各チャンネルに名前を設定
3. 例: "メイン", "サブ", "緊急"など

## 使用方法

### 基本的な操作

1. **チャンネル選択**
   - パネルのチャンネルボタンをクリック
   - 現在のチャンネルが表示される

2. **送信方法**
   - PTTボタンを押しながら話す
   - またはトグルモードで常時送信

3. **受信**
   - 同じチャンネルの音声を自動受信
   - 音量調整可能

### PTT（Push to Talk）設定

#### PTT Mode
- 0: ホールド（押している間送信）
- 1: トグル（押すごとに切り替え）
- 2: 音声検出（自動送信）

#### Voice Activation Threshold
- 音声検出モードの感度
- デフォルト: -35dB
- 環境に応じて調整

### 全チャンネル発報

緊急時や重要な連絡に使用：

1. 「All Call」ボタンを押す
2. 全チャンネルに音声が送信される
3. 通常より高い優先度で処理

:::warning 使用上の注意
全チャンネル発報は緊急時のみ使用してください。頻繁な使用は他のユーザーの迷惑になります。
:::

## 高度な設定

### 音質設定

#### Audio Quality
- Low: 低帯域幅、低品質
- Medium: 標準品質（推奨）
- High: 高品質、高帯域幅

#### Noise Suppression
- ノイズ抑制レベル（0-100%）
- デフォルト: 50%

### 送受信設定

#### Transmit Power
- 送信強度（0.1-2.0）
- デフォルト: 1.0

#### Receive Sensitivity
- 受信感度（0.5-2.0）
- デフォルト: 1.0

#### Squelch Level
- スケルチレベル（ノイズカット）
- デフォルト: -50dB

## スタッフ運用での活用

### チャンネル割り当て例

イベント運営での推奨割り当て：

```
1ch: メイン連絡用
2ch: 受付・案内
3ch: 技術スタッフ
4ch: セキュリティ
5ch: 緊急連絡用
6-12ch: 予備
```

### グループ別設定

1. **運営スタッフ用**
   - 全チャンネルアクセス可能
   - All Call権限付与

2. **一般スタッフ用**
   - 指定チャンネルのみ
   - All Call権限なし

3. **参加者用**
   - 限定チャンネルのみ
   - チーム戦などで使用

## パフォーマンス最適化

### 帯域幅の管理

1. **Audio Quality**を環境に応じて調整
2. 使用しないチャンネルは無効化
3. 同時通話人数を制限

### 遅延の最小化

1. **Buffer Size**を最小限に
2. **Update Rate**を適切に設定
3. ネットワーク品質を考慮

## トラブルシューティング

### 通信できない

確認事項：
- [ ] 同じチャンネルに設定されているか
- [ ] PTTが正しく動作しているか
- [ ] 音量設定が適切か
- [ ] チャンネル権限があるか

### 音質が悪い

対処法：
1. Audio Qualityを上げる
2. Noise Suppressionを調整
3. 送信強度を確認

### 遅延が大きい

対処法：
1. Buffer Sizeを減らす
2. Update Rateを上げる
3. 他の通信を減らす

## 実装例

### イベント運営での使用

```
設定例：
- Panel数: 5（各持ち場に1つ）
- チャンネル構成:
  - 1ch: 全体連絡
  - 2ch: 受付
  - 3ch: ステージ
  - 4ch: 技術
  - 5ch: 緊急
```

### ゲームワールドでの使用

```
設定例：
- Panel数: 2（各チームベースに1つ）
- チャンネル構成:
  - 1-6ch: チームA用
  - 7-12ch: チームB用
```
