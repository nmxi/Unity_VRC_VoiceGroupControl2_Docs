# Voice Group Control 2 へようこそ

Voice Group Control 2（VGC2）は、VRChatワールドで使用できる高度な音声制御システムです。

## 主な機能

- **グループベース音声制御**: プレイヤーを空間的なグループに分けて音声を管理
- **音声増幅機能**: マイクやトランシーバーを使った遠距離通信
- **リアルタイムミキサー**: グループ間の音量をGUIで調整
- **設定の永続化**: プリセット保存とJSON形式でのエクスポート/インポート
