# ベストプラクティスガイド

VGC2を効果的に使用するための推奨設定、設計指針、運用方法をまとめています。このガイドに従うことで、最適なパフォーマンスとユーザー体験を実現できます。

## ワールド設計のベストプラクティス

### エリア分割の考え方

#### 基本原則

1. **明確な境界を設定**
   - 物理的な壁や建物で区切る
   - 視覚的に分かりやすい境界線
   - プレイヤーが意識しやすい区分け

2. **適切なエリアサイズ**
   ```
   推奨サイズ：
   - 小部屋: 5×5×3m
   - 中規模ルーム: 10×10×4m
   - 大ホール: 20×20×6m
   - 屋外エリア: 30×30×10m
   ```

3. **エリア間の接続**
   - 通路には専用グループを割り当て
   - フェード距離を2-3mに設定
   - 重要な場所は優先度を高く

### グループ数の決め方

#### 用途別推奨グループ数

| 用途 | 推奨グループ数 | 理由 |
|------|----------------|------|
| 小規模イベント | 3-4 | シンプルな構成で管理しやすい |
| 中規模イベント | 5-8 | 柔軟な音声制御が可能 |
| 大規模イベント | 8-12 | 細かいエリア分けが必要 |
| ゲームワールド | 4-6 | パフォーマンスとのバランス |

#### グループ割り当て例

```
イベント会場の例：
- Group 0: エントランス
- Group 1: メインステージ
- Group 2: 展示エリアA
- Group 3: 展示エリアB
- Group 4: 休憩スペース
- Group 5: スタッフルーム
- Group 6: VIPルーム
- Group 7: 屋外エリア
```

### エリアサイズの最適化

1. **プレイヤー密度を考慮**
   - 高密度エリア: 小さめに分割
   - 低密度エリア: 大きめでOK

2. **音響特性に合わせる**
   - 静かなエリア: 広めに設定
   - 騒がしいエリア: 狭めに設定

3. **移動パターンを分析**
   - 主要動線上は細かく分割
   - 滞在時間が長い場所は独立したグループ

## マイク機能の効果的な使い方

### イベント司会での活用

1. **配置戦略**
   - ステージ中央に1本
   - サブステージに1本
   - 控室に予備1本

2. **設定例**
   ```yaml
   メインマイク:
     Mode: 0 (使用者のみ)
     Amplification Range: 100m
     Volume Multiplier: 3.0
     Priority: 1
   ```

3. **運用ルール**
   - マイクの受け渡し手順を決める
   - リスポーン位置を明確に
   - 緊急時の対応を共有

### 複数マイクの管理

1. **優先順位の設定**
   ```
   Priority設定:
   - メインマイク: 1
   - サブマイク: 5
   - 予備マイク: 10
   ```

2. **グループ制限**
   - 特定グループ専用マイクの活用
   - スタッフ専用マイクの設置

#### 運用ルール

1. **通信規律**
   - コールサインの使用

2. **緊急時対応**
   - 5chを緊急専用に

## パフォーマンス最適化のコツ

### プレイヤー数に応じた調整

#### 自動調整スクリプト例

```csharp
if (playerCount > 40) {
    // 高負荷時の設定
    UpdateInterval = 0.2f;
    PerformanceMode = Low;
    MaxActivePlayers = 30;
} else if (playerCount > 20) {
    // 中負荷時の設定
    UpdateInterval = 0.1f;
    PerformanceMode = Normal;
    MaxActivePlayers = 40;
} else {
    // 低負荷時の設定
    UpdateInterval = 0.05f;
    PerformanceMode = High;
    MaxActivePlayers = 60;
}
```

### モバイル対応の考慮点

1. **Quest最適化**
   - グループ数を最小限に
   - エフェクトを無効化
   - 更新頻度を下げる

2. **帯域幅の管理**
   - Audio Quality を Medium 以下
   - 不要な機能を無効化
   - 同時通話数を制限
