# パススルーモードについて

パススルーモードは、VGC2の音声管理機能を一時的に無効化する機能です。

:::tip ヒント
パススルーモードを有効化することで、グループエリアに設定されている音量設定を一時的に全て無効化することができます。
:::

## 使用例

イベント中は音声の分離を行い、イベント終了後に不要の場合にパススルーモードを有効化することで、音声の分離がなくなり、自由な会話がしやすくなる。といった使い方が可能です。

## IgnorePassthroughMode設定

:::tip ヒント
スタッフルームなど、音を確実に管理し続けてほしいエリアなどにはIgnorePassthroughModeを有効にすることをおすすめします。
:::

パススルーモード時も強制的に音声の管理を行いたい場合は、グループエリアの設定にあるIgnorePassthroughModeを有効化してください。

### 設定方法

グループエリアミキサーまたは、UnityEditor上でGroupAreaコンポーネント内の変数から設定が可能です。

### 推奨される使用場所

- スタッフルーム
- 控室
- その他、常に音声を遮断したいエリア
